## Eğitim Süreçlerinde LLM API Entegrasyonu

### Atölye Kapsamı
Bu atölye çalışması; eğitim araştırmacıları, akademisyenler ve lisansüstü öğrenciler için büyük dil modeli (LLM) API'larını akademik ve eğitsel süreçlere sistem düzeyinde entegre etmeyi hedefleyen teknik bir uygulama programıdır. Katılımcılar; ölçme-değerlendirme, Bloom taksonomisi sınıflandırması, soru kalite analizi ve yapılandırılmış literatür çıkarımı gibi vakalar üzerinden, LLM'leri yalnızca birer sohbet aracı olmaktan çıkarıp ölçeklenebilir birer çözüm bileşeni olarak konumlandırmayı öğreneceklerdir. Program boyunca API mantığı, JSON formatında yapılandırılmış çıktı üretimi ve otomatik raporlama teknikleri ele alınarak, akademik iş akışlarının tekrarlanabilir ve sistematik hale getirilmesi üzerinde durulacaktır. Atölye sonunda katılımcılar, LLM teknolojilerini kendi akademik projelerine ve eğitim ortamlarına entegre edebilecek, veri odaklı ve otomatikleştirilmiş iş akışları tasarlama yetkinliği kazanmış olarak süreci tamamlayacaklardır.
